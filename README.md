# Bem Estar Fitness — landing page

Landing page da Academia Bem Estar Fitness (Jardim de Piranhas/RN e Brejo do Cruz/PB), feita com React + Vite, `motion` e componentes do [React Bits](https://reactbits.dev).

## Rodar no computador

```bash
npm install
npm run dev
```

## Onde editar

- `src/config.js` — WhatsApp, unidades, horários, depoimentos, perguntas frequentes e mídias.
- `public/inauguracao.json` — aviso do dia sobre a inauguração (`"AAAA-MM-DD": "texto"`). Sem entrada para o dia, o site mostra a mensagem automática.
- `public/media` e `public/brand` — fotos, vídeos, logo e ícones.

Cada envio para a branch `main` publica o site automaticamente na Vercel.
